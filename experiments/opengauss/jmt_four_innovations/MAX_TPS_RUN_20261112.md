## 代码补足

### AP CPU 不再在 DP 中消失

`QueryOption.cpu_seconds` 和 `ParetoState.ap_cpu_seconds_per_second`：

- 并发 CPU 需求按各查询 `CPU_seconds / wall_seconds` 分别相加；
- Pareto 比较保留 CPU 维度，不能因为 IO 少就剪掉低 CPU 方案；
- `None` 是未知，不能当0；新联合入口缺 CPU 输入会明确拒绝。

`current_joint.evaluate_current_joint()`：

- 真实搜索多个当前标定 SB 点；
- SB/AP 共享同一个调用方明确的总池，预算是 `pool - SB`；
- 最大化 TP TPS，然后以 AP 时间/内存打破**完全相同 TPS**的平局；
- 不自动引入3%近最优阈值，不在未建模时固定8192；
- 可保持运行中查询原 WM，不让静态阶段表暗中修改正在执行的 SQL；
- 未知资源/域外预测是失败候选，不是零成本或胜出候选。

### CPU 与 IO 在同一个 TP 固定点求解

`cpu_fixed_point.solve_cpu_tps()` 和 native `_predict_tps()` 的可选 CPU 路径：

- 使用独立 TP CPU秒/事务、AP CPU秒/秒和 CPU容量；
- TPS 下降时同步降低 TP CPU负载，不再因基线负载固定而突变成零 TPS；
- IO延迟函数在**同一个候选 TPS**处重算队列，与 CPU 一起二分求解；
- 没有查询编号或阶段编号修正系数。

旧 strict/native 入口的证据门禁没有关闭；新 CPU-aware current 入口必须
接入真实的完整 AP 资源预测后才会成为五阶段输出。

### 在线搜索增加明确工作量上限

新 current 联合入口在所有 SB 点之间共享同一工作量预算：最多10万次状态展开、
100万次支配比较、512次性能预测。不靠截断 Pareto 前沿冒充精确最优。
超限返回 `selected=null / search_complete=false`，保留诊断，不发布局部最优。
后续应依算子临界点/计划变化压缩 WM 候选，再执行完整搜索。

合成的5查询×33WM×4SB压力例在本机约1.69秒触发比较预算；
**这是过载拒绝耗时，不是完成全域搜索或准确率证明**。
旧入口不因新增可选预算参数而改变原结果。

## 本轮新发现及通用修复

### Q9：Merge Join 上游基数输入覆盖缺口

原结构算子已经处理 Merge Join，但学习基数适配只支持部分 Hash Join /
经认证 Nested Loop。Q9 的盲计划把一个关键 Merge Join 估成2263行，
后续 Hash 建表及外侧大表落盘风险因此可能被隐藏。原预测约3.15GiB逻辑写，
实际却触发16GiB临时文件大小限制。

这证明该点的风险判断不能采信；**临时文件限额不是累计写量真值，
失败执行也没有完整实际计划，因此不据此计算精确误差或断定唯一原因。**

新增 `join_sample.py` / `collect_join_sample.py`：

- 一个大表锚点按块直接采样，维表保留完整；按连接结果 count/p 估计 N；
- 单条 CTE 链复用各连接前缀，避免重复扫描所有完整输入；
- 3个预先指定种子，稀疏或波动大的结果拒绝，不把缺失当0；
- 根据完整语义谓词、基表别名及数据水印绑定到 Inner Hash/Merge/Nested Loop，
  不依赖 Q9 编号或某个 WM 的计划行数；
- 最多64项、最多6小时TTL；数据变化/过期失效，未扩展到外连接/半连接；
- Q9 的5层连接采样 SQL 已通过本机 openGauss EXPLAIN-only 检查。
  **真实采样尚在队列中，未宣称修复后精度已经验证。**

### Q18：HAVING 前分组数的轻量在线输入

新增 `key_group_sample.py` / `collect_key_group_sample.py`。
离线扫描时通过整数键哈希选完整键，保留选中键的全部行，用 d/p 估计分组数，
同时保存至多256个频数桶；不是对行样本的 NDV 直接除以采样率。

在线只查水印及小摘要；不扫描5亿行、不执行目标 ANALYZE、不读取真实
HAVING 输出当建表分组数。仅支持无筛选普通基表的非空整数分组键；
样本估计 N 与输入规模不一致时拒绝 G-only 替代，误差假设明确保留。
本机整数哈希 SQL 的 EXPLAIN-only 检查已通过，**实际离线采样/较高WM
复测尚在队列，不能把该修复当作已验收的效果。**
