# 创新三：可搬走的标准库冻结演示

Python 3.8+即可，无需openGauss、NumPy、DeepDB或原始trace。

```bash
bash demo.sh
```

包含：
- 每query算子候选曲线（冻结的创新二输入）。
- 当前实例/机器余量规划两场景，各5阶段×11SB点。
- 生产solver回放、另一份未剪枝参考DP及小规模全枚举。
- 20项本组件标准库测试。主仓库全回归657项通过，不在本简包中冒充全部可跑。
- 固定运行中WM的反事实连续启动检查，在SB=4GiB的S3拒绝准入。

每阶段独立最优有解，不代表贪心直接串联五阶段可行。
机器余量场景还需扩大原生进程上限/联动动态保护，并未在当前实例应用。
源JSON保留原始路径作证据，但演示不读取这些路径，不续期，不访问DB。
不表示新机器/新WM spill准确；Q21仍有已知偏差，物理峰值和完整混合TPS未验收。
这是创新三离线展示简包，不是全部四项创新和魔改openGauss的完整发布包。
