# 当前 SB 上界：第一个 SB miss 不再明显下降区间的右端点

本次按用户指定的新定义，替换原“最大SB命中率的99%”规则。规则改动发生在查看本次轨迹之后，不能冒称阈值的事前独立验证。

## 判据与结果

令 m(B)=1−P_SB(B)，对相邻容量计算：

```text
每增加1 GiB减少的SB miss/万次访问
  = max(0, m(B_left) − m(B_right)) × 10000 / ((B_right−B_left)/1024)
```

默认“无明显下降”阈值为 **不超过1次/万次逻辑访问/GiB**，由显式参数控制；并不是剩余miss相对下降不超过1%。取第一个满足条件区间的**右端点**，所以3→4 GiB满足就选4，不选3。若未观测到下降阶段，或者后面又出现显著收益，则拒绝把它作为自动硬剪枝证据。

|拓扑|区间 GiB|每增1 GiB减少的SB miss/万次访问|是否无明显下降|
|---|---:|---:|---|
|TP128|2→3|12.939024|否|
|TP128|3→4|0.075227|是|
|S5_128_plus_16|2→3|11.744618|否|
|S5_128_plus_16|3→4|0.091636|是|

**模拟上界：TP128=4 GiB；S5_128_plus_16=4 GiB。** 没有将4096写成选择常量；其它曲线也按相同参数和端点规则计算。
